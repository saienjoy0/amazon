# Global SSD Career Cohort — Phase 1

Updated: 2026-09-09

## Purpose

Amazon Sub-Same-Day (SSD)を「成功例だけ」ではなく、SSD現場に入った人を起点に追跡し、2026年時点でどこへ進んでいるかを見る。

最終目標は、SSDがFC/DSよりも本当に以下につながりやすいかを検証すること。

- L5 / L6昇進
- Site Lead
- Ops Excellence / Central Ops
- Launch / Network role
- Program Manager / Corporate
- Amazon外への転職

## Important limitation

これは**第1次コホート**。公開LinkedIn/Web検索でSSD在籍が明示された人を広く拾ったが、LinkedIn公開範囲・検索インデックスに依存する。

したがって、以下の比率をAmazon全体の母集団比率として扱ってはいけない。

また、2021〜2024年にSSDへ入った人物だけで完全に統一できていない。SSDへの入職年が公開されないプロフィールが多いため、今回は以下に分けた。

1. **Core cohort**: SSD現場AM/OM/Site Leadとして確認できる人物
2. **Bridge cases**: 通常Ops → SSD Corporate / Program / Strategyへ移った人物
3. **Adjacent cases**: SSD Launch / Planning / PM側からのキャリア

# 4. Current interpretation

## A. 「SSDならPMへ行きやすい」はまだ未証明

今回のCore cohortだけを見ると、SSDに入った人の多くはまず

- AM II
- Operations Manager
- Site Lead

へ進んでいる。

したがって、SSD配属そのものが自動的にPM転換を生む証拠はない。

## B. SSDの強みは「出口の隣接性」

一方で、SSD network周辺には実際に

- Ops Integration
- Planning
- Capacity
- Launch & Expansion
- Ops Strategy
- Central Operations
- Supply Chain
- Program Management

が存在する。

普通のSite Opsから上流へ移るための**橋渡し職が多い**ことはかなり確からしい。

## C. 強いキャリアは「SSD + Launch/Network Project」

現時点で最も再現性がありそうなのは

SSD AM
→ AM II / L5
→ Launch / Network standardization / tool deployment / Ops Excellence
→ OM or Central role
→ Program Manager

というパターン。

# 5. What this means for Japan new-grad AM

Amazon JapanでSSDを希望する場合、狙うべきなのは「SSDに入ること」自体ではなく、入った後に以下を取れるか。

### Year 1
- End-to-end flow理解
- Safety / Quality / Productivity / Costで強い実績
- PA/AA people management

### Year 1–2
- Site launch / expansion
- 新process導入
- labor planning
- automation / tooling
- standardization

### Year 2–3
- Site外 / network-level project
- Ops Excellence
- Central Operations
- Launch & Expansion
- Planning

### Then
- Program Manager / Senior PM

# Bottom line after Phase 1

SSDは「PM養成部署」ではない。

しかし、複数国の公開キャリアから見ると、SSDは通常Site Opsよりも

- Launch
- Network expansion
- Planning
- Standardization
- Central control
- Ultra-fast delivery strategy

との距離が短い。

したがって、将来Program Manager / Corporateを狙う新卒AMにとってSSDは**有力な配属候補**。ただし本当にFC/DSより転換率が高いかはPhase 2比較コホートで検証が必要。
